### 2. **Required Documents Status Update - SQL Parameter Error**
**Error**: `SQLSTATE[HY093]: Invalid parameter number`
**Location**: `api/logs.php` (POST method for docs)
**Root Cause**: `ON DUPLICATE KEY UPDATE` clause requires duplicate parameter binding
**Fix**: 
- Updated SQL query to use `:status_update` for the UPDATE clause
- Bound `status` parameter twice in the execute array

**Code Change**:
```php
$stmt = $pdo->prepare("
    INSERT INTO beneficiary_documents (beneficiary_id, document_name, status)
    VALUES (:beneficiary_id, :doc_name, :status)
    ON DUPLICATE KEY UPDATE status = :status_update
");

$stmt->execute([
    'beneficiary_id' => $beneficiaryId,
    'doc_name' => $docName,
    'status' => $status,
    'status_update' => $status  // Duplicate binding for UPDATE clause
]);
```

### 4. **Accomplishment Report Period Calculation**
**Error**: Period showing "Next Period" instead of proper date range
**Location**: `modal.js` - Add AR button handler
**Root Cause**: Incomplete error handling in period calculation logic
**Fix**: 
- Rewrote period calculation with proper parsing
- Added fallback logic for edge cases
- Improved date range formatting

**Expected Behavior**:
- First AR: Based on beneficiary start date → `Jan 01 - 15, 2026`
- Subsequent ARs: Auto-increment by 15 days → `Jan 16 - 31, 2026`, then `Feb 01 - 15, 2026`

**Code Change**:
```javascript
// Parse: "Jan 01 - 15, 2026" or "Jan 16 - 31, 2026"
const parts = lastText.split(',');
const yearPart = parseInt(parts[1].trim());
const monthDayPart = parts[0].trim();
const monthStr = monthDayPart.split(' ')[0];
const monthIdx = new Date(Date.parse(monthStr + " 1, 2012")).getMonth();

if (monthDayPart.includes('01 - 15')) {
    // Last was 1-15, next is 16-end
    const lastDay = new Date(yearPart, monthIdx + 1, 0).getDate();
    nextPeriod = `${monthStr} 16 - ${lastDay}, ${yearPart}`;
} else {
    // Last was 16-end, next is 1-15 of next month
    const nextDate = new Date(yearPart, monthIdx + 1, 1);
    const nextMonthStr = nextDate.toLocaleString('en-US', { month: 'short' });
    const nextYear = nextDate.getFullYear();
    nextPeriod = `${nextMonthStr} 01 - 15, ${nextYear}`;
}
```
